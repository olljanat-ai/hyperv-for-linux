hyperv-for-linux apt repository

Adds the Microsoft Hypervisor and a matching Hyper-V capable kernel to Ubuntu. Repo URL: https://olljanat-ai.github.io/hyperv-for-linux

Install

# Trust the signing key
sudo install -d /etc/apt/keyrings
curl -fsSL https://olljanat-ai.github.io/hyperv-for-linux/public.key \
  | sudo tee /etc/apt/keyrings/hyperv-for-linux.gpg >/dev/null

# Add the repository
echo "deb [signed-by=/etc/apt/keyrings/hyperv-for-linux.gpg] \
  https://olljanat-ai.github.io/hyperv-for-linux stable main" \
  | sudo tee /etc/apt/sources.list.d/hyperv-for-linux.list

sudo apt-get update
sudo apt-get install linux-image-hyperv hyperv

What's in here

  • linux-image-hyperv — Ubuntu kernel rebuilt with MSHV_ROOT + Hyper-V drivers + EFI loader patch.
  • hyperv — Microsoft Hypervisor binaries + firmware, repackaged from packages.microsoft.com/azurelinux/3.0/prod/non-oss/.
